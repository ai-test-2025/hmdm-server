#Tomcat Setup
1. Download from  https://tomcat.apache.org/download-90.cgi
`64-bit Windows zip
2. Unizip the downloaded file to folder (C:\AI\tomcat9)

3. Go to /bin and open catalina.bat in notepad 
add the below line under setlocal section
SET JRE_HOME=C:\AI\zulu8\jre #Modify the path value as per your java binary path

4. To verify tomcat is running correctly
   open cmd and navigate to tomcat bin folder
   run startup.bat
5. Enter http://localhost:8080/ in browser to verify tomcat default page is showing up
